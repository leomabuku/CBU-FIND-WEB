# Contributing

1. Read `docs/ANDROID_WEB_CONNECTION.md` before changing Firestore fields or enums.
2. Create a short-lived branch.
3. Keep environment files and credentials untracked.
4. Make focused changes and preserve accessible labels, keyboard use, and responsive layouts.
5. Run `npm run lint` and `npm test`.
6. Verify at least one Android ↔ web workflow when data behavior changes.
7. Explain schema, rules, index, and deployment impacts in the pull request.

Avoid force pushes to shared branches and do not deploy rules from an unreviewed branch.
